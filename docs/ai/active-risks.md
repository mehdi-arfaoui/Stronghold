# Active Risks

Version: 1

- Contract drift: estimated, suggested, validated, or fallback RTO/RPO values could accidentally be treated as proof.
- Evidence drift: observed or declared evidence could be mistaken for measured tested evidence.
- Graph coupling: graph scenario simulation could leak estimate semantics into contract verdicts.
- Scope creep: AI tooling changes could accidentally touch AWS scanners, server, web, or Phase 5 product behavior.
- RTK confusion: summarized RTK output could be mistaken for authoritative contract, evidence, CI, release, or JSON/YAML output.
- Context drift: agent memory docs can become stale unless scripts surface current git state and risks.
